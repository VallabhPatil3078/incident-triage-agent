# Commit & Version Control Standards

You are required to follow these industry standards for version control in this repository:

1. **Check for Secrets:** Before staging or committing ANY code, ALWAYS inspect the changes to ensure no private information, secrets, API keys, or sensitive credentials are being pushed.
2. **Timely Commits & Pushes:** Commit and push your work to the remote repository every time a major task (e.g., a Phase in PLAN.md) is completed. Keep the git history clean and descriptive.
